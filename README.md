## How to host (free & easy)

### Option 1 — Netlify Drop (fastest)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire `engagement-invitation` folder (must include both `index.html` and `styles.css`)
3. Get a live link instantly (you can later claim a custom subdomain)

### Option 2 — Vercel
1. Go to [https://vercel.com](https://vercel.com) → New Project → Upload
2. Upload the folder

### Option 3 — GitHub Pages
1. Create a new public repo
2. Upload `index.html`
3. Settings → Pages → Deploy from main branch

### Option 4 — Any static host
Just upload `index.html` to any web server / shared hosting / Cloudflare Pages / Firebase Hosting, etc.

## Customize before sharing

Open `index.html` in a text editor and search for these:

| What to change              | Location in file                  |
|----------------------------|-----------------------------------|
| Couple names               | Cover + Hero sections             |
| Date / time / venue        | Details card + cover              |
| Invitation message         | Message section                   |
| Google Maps link           | Venue section (`maps.google.com`) |
| Music (optional)           | `<audio>` source URL              |

## Local preview

Simply open `index.html` in any modern browser (Chrome / Safari / Firefox).  
Music may be blocked until user interaction (browser policy).
